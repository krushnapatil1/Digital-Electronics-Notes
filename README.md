# 📘 Digital Electronics Notes

Welcome to my **Digital Electronics Notes** repository!

This repository contains structured notes, explanations, truth tables, logic diagrams, circuit designs, and important concepts of Digital Electronics. It is designed for beginners, engineering students, and anyone interested in learning the fundamentals of digital systems.

The main goal of this repository is to build a strong foundation in Digital Electronics, which is essential for learning **Verilog, SystemVerilog, RTL Design, VLSI Design, and Design Verification**.

## 📚 Topics Covered

### 1. Number Systems and Codes
- Introduction to Digital Electronics
- Binary, Decimal, Octal, and Hexadecimal Number Systems
- Number System Conversions
- 1's and 2's Complement
- Binary Arithmetic
- BCD Code
- Gray Code
- ASCII Code

### 2. Logic Gates
- AND Gate
- OR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- XOR Gate

- Truth Tables and Boolean Expressions

### 3. Boolean Algebra
- Boolean Algebra Laws

- De Morgan's Theorems

- SOP and POS Forms
- Canonical Forms

### 4. Combinational Logic Circuits
- Half Adder
- Full Adder
- Half Subtractor
- Full Subtractor
- Multiplexer (MUX)
- Demultiplexer (DEMUX)
- Encoder
- Decoder

- ALU (Arithmetic Logic Unit)

### 5. Sequential Logic Circuits

- Latches

- JK Flip-Flop

- T Flip-Flop

- Flip-Flop Conversion

### 6. Registers and Counters
- Shift Registers
- SISO, SIPO, PISO, PIPO

### 7. Memory Devices

### 8. Important Digital Concepts
